# bookkeeping-push-fail-fast — Input

Eradicate silent error swallowing in worktrees.py — commit_bookkeeping_to_main returns success on push failure, _ensure_todo_on_remote_main swallows fetch/ls-tree errors, _create_or_attach_worktree has no precondition check for todo existence on origin/main. Every failure must: (1) print actionable recovery instructions to the agent, (2) fail fast with a non-success return, (3) log at appropriate severity. The push-deferred path that returns True is the root cause of a cascading failure where worktrees branch from stale origin/main and workers operate on incomplete todo directories. The fix must also wire _ensure_todo_on_remote_main into the dump→prepare path so worktree creation has a hard guarantee that scaffold artifacts exist on origin/main.
